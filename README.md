# AsyncStreams

This solution accompanies the C# 8 async streams example. `AsyncStreams/`
contains the C# console application and benchmarks; `MovieDb/` contains the
database project. The application targets .NET Core 3.1.

Read [C# 8 - Async Streams](https://matlus.com/writing/csharp-8-async-streams/)
for the full explanation of asynchronous iteration, how the database reader is
used, and the qualifications needed when interpreting the benchmark. The
[original recording](https://www.youtube.com/watch?v=2J9AylG6eHg) is also
available.
